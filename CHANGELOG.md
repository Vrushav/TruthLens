## [1.0.0] - 2026-07-22

### Added
- Initial public release of TruthLens.
- Command-line interface (CLI) for Python source code analysis.
- AI-generated code trust validation.
- Static code analysis pipeline.
- Security vulnerability detection.
- Hallucination detection and trust scoring.
- HTML report generation with a modern dashboard.
- JSON report generation.
- Automatic browser launch for HTML reports.
- Severity-based issue classification.
- Modular project architecture for future expansion.
- Professional project packaging with `pyproject.toml`.

### Security
- Detection of insecure coding patterns.
- Identification of weak cryptographic algorithms.
- Detection of hardcoded secrets.
- Detection of command injection risks.
- Runtime error detection.
